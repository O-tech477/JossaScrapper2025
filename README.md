# JossaScrapper

JossaScrapper is a small JoSAA analytics app built with Streamlit and SQLite. It combines scraped JoSAA opening/closing rank data with a PDF-based IIT branch cache so you can explore admission cutoffs, filter by rank, and inspect seat allocation patterns by branch.

## Quick Start

If the JOSAA 2025 website is down, skip the scraper and launch the dashboard directly:

```bash
streamlit run app.py
```

## What it does

- `Got This Rank ?` helps you filter historical allotment data by category, gender, quota, round, rank, and institute type.
- `Dream College ?` lets you pick an institute and inspect cutoff history for a chosen category and round.
- `Best IIT for this ?` reads the cached JIC 2025 PDF report and shows which IITs took seats for a selected branch.
- The sidebar includes a downloadable copy of the local PDF report if it is present in the project folder.

## Project Structure

- `app.py` - Streamlit dashboard and query UI.
- `scrapper_2025.py` - Selenium scraper that collects JoSAA allotment data and stores it in SQLite.
- `database_manage.py` - Creates and populates `database.db` using a star-schema layout.
- `pdf_reading.py` - Parses `JICReport2025.pdf` and builds the IIT branch seat cache.
- `main.py` - Convenience entry point for rebuilding the branch cache database.
- `schema.sql` - SQLite schema for the analytics database.
- `database.db` - Local analytics database generated by the scraper.
- `iit_branch_seats.db` - Cached branch seat summary generated from the PDF report.

## Requirements

- Python 3.14 or newer
- Google Chrome installed for Selenium scraping
- The local report file `JICReport2025.pdf` in the project root for the branch analysis tab

## Installation

Create and activate a virtual environment, then install the project dependencies:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
```

If you want to run the scraper from a fresh machine, make sure ChromeDriver is available through your Selenium setup.

## How to Run

### 1. Build the branch cache

This parses the PDF report and creates or refreshes `iit_branch_seats.db`:

```bash
python main.py
```

### 2. Scrape and populate the analytics database

This launches the JOSAA scraper and fills `database.db`:

```bash
python scrapper_2025.py
```

### 3. Start the dashboard

```bash
streamlit run app.py
```

## Data Flow

1. `scrapper_2025.py` opens the JoSAA allotment pages and extracts the result table.
2. `database_manage.py` stores the scraped rows in `database.db` using dimension and fact tables.
3. `main.py` builds `iit_branch_seats.db` from the PDF report for the branch explorer tab.
4. `app.py` reads both SQLite databases and serves the Streamlit interface.

## Notes

- The app expects the generated SQLite databases to live in the project root.
- If you refresh the scraper output or replace the PDF, rebuild the cache before reopening the dashboard.
- Some institute names in the raw data are inconsistent, so the database classifier normalizes whitespace before deciding whether a row is IIT, NIT, IIIT, or GFTI.
